## 🚀 Resumen de los Ejercicios

1. **Ejercicio 1: Explicación del "Mapeo" en Python**
   - Análisis técnico de la comprensión de listas empleada como mecanismo de mapeo, efectos secundarios, retorno implícito `None`, recolección de basura y equivalencia en programación funcional pura.

2. **Ejercicio 2: Frutas Favoritas**
   - Implementación de la función `mostrar_fruta` y mapeo en una sola línea.
   - Respuestas razonadas a las 5 preguntas conceptuales de reflexión.

3. **Ejercicio 3: Subida de Notas (+1 punto)**
   - Respeto estricto a la estructura obligatoria de `main()`.
   - Comparativa crítica profunda entre la *Opción 1* (bucle imperativo `for`) y la *Opción 2* (sintaxis declarativa de mapeo).

4. **Ejercicio 4: Aplicación React de Gestión de Notas (20 Alumnos)**
   - Proyecto modular en Vite/React bajo arquitectura **MVC**, funciones puras y menú de operaciones.
   - Respuestas justificadas a las preguntas metodológicas sobre calidad de código y equivalencia con `[mostrar_alumno(...) for ...]`.

5. **Ejercicio 5: Algoritmo de Cruce y Torsión con Gráficos de Asteriscos (`*`) en React**
   - Aplicación interactiva en React que traduce la lógica de intercambio y rotación de pares a representaciones visuales y patrones textiles/geométricos generados con símbolos asterisco (`*`).
   - Script de referencia en Python para ejecución directa por terminal.
